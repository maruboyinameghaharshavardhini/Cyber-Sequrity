# 🛡️ CyberShield – Cyber Security Awareness Website

## 📌 About the Project

CyberShield is an interactive website designed to promote cybersecurity awareness and help users stay safe in the digital world. It provides simple explanations of common cyber threats and practical tips for protecting personal information and online accounts.

## ✨ Features

- **Home:** Introduction to cybersecurity awareness.
- **Cyber Threats:** Learn about phishing, malware, ransomware, social engineering, password attacks, and identity theft.
- **Stay Safe:** Explore tips for strong passwords, multi-factor authentication, safe browsing, software updates, privacy, and backups.
- **Cybersecurity Quiz:** Test your knowledge with interactive multiple-choice questions.
- **Phishing Test:** Practise identifying suspicious emails.
- **About:** Learn about the project's purpose.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Project Objective

The main objective of CyberShield is to make cybersecurity awareness simple, accessible, and interactive. The project encourages users to recognise online threats and develop safer digital habits.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open the main HTML file in a web browser.
4. Explore the sections, take the quiz, and try the phishing awareness test.
